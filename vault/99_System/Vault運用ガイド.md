# Vault運用ガイド

> `99_System` は**メモを入れる場所ではなく、このVaultをどう使うかのルール・仕組み（取扱説明書）**を置く場所。
> メモが"中身"だとしたら、ここは"取扱説明書"。

## このVaultの考え方

大きく2つに分かれている。

1. **メイン部分（番号付き）** … 自分が毎日触る／AIに整理してもらうところ
2. **システム的なところ（`_system/`）** … AIに動いてもらうための裏方。普段は開かない

## 情報の流れ（番号＝作業の流れ）

情報は下から上に流れていく：

```
集める（01_Inbox・08_Clipping）
   ↓
整理する（07_Research）
   ↓
記録する（04_Daily〜06_Monthly）
   ↓
種にする（03_ContentSeeds）
   ↓
完成（02_Contents）
```

## フォルダ一覧と役割

| フォルダ | 役割 |
| --- | --- |
| `01_Inbox` | 自分の未分類メモの入口（一次情報） |
| `02_Contents` | 完成したコンテンツの置き場 |
| `03_ContentSeeds` | 発信の種（気づき・切り口・体験の断片） |
| `04_Daily` | 日報・デイリーノート |
| `05_Weekly` | 週報（日報からまとめる） |
| `06_Monthly` | 月報（1ヶ月分からまとめる） |
| `07_Research` | 外部記事をAIで要約・整理した置き場 |
| `08_Clipping` | 外部記事のクリップ専用（借り物） |
| `99_System` | Vaultの使い方・ルール（このガイド） |

## 2つの入口を分ける理由

- `01_Inbox` ＝ 自分の言葉（一次情報）
- `08_Clipping` ＝ 他人の言葉（借り物）

混ざると、AIに渡すとき「自分の考えか、記事の受け売りか」が分からなくなる。
**入口の時点で分けておく**のが重要。

## AIへの依頼ルール

- 元の素材（クリップ）は書き換えない
- 整理結果は別フォルダ（`07_Research` など）に出してもらう
- 裏方の指示ファイルは `_system/`（AGENTS.md / CLAUDE.md / tools）に置く

## メモ
- フォルダは作り込みすぎない。AIがいい感じに整理してくれる。
- 04〜06は1つにまとめてもよいが、読みやすさのために分けている。
- 自分の発信が回る並びを考えると、フォルダ整理が楽しくなる。
