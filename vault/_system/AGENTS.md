# AGENTS.md

このVaultでAIエージェントが作業するときの指示。

## このVaultの構造
- メイン部分（番号付きフォルダ `01`〜`08`, `99`）が"中身"。
- `_system/` が裏方。普段ユーザーは開かない。

## 情報の流れ
集める（01_Inbox・08_Clipping）→ 整理（07_Research）→ 記録（04〜06）→ 種（03_ContentSeeds）→ 完成（02_Contents）

## 守るべきルール
1. **元素材を書き換えない。** `08_Clipping` のクリップは原文のまま残す。
2. **整理結果は別フォルダへ出す。** 外部記事の要約・整理は `07_Research` に新規作成する。
3. **入口を混ぜない。** `01_Inbox`（自分の言葉）と `08_Clipping`（他人の言葉）を混同しない。
4. 詳しい運用方針は `99_System/Vault運用ガイド.md` を参照する。
