# 00_Companies（会社の前提）

AIに**各社の前提（会社概要・事業・トーンなど）を覚えさせておく**ための場所。

ここに書いた内容を、AIが発信・整理・要約をするときの「共通の記憶」として参照する。

## 中身
- `RePlayce/会社前提.md`
- `EQUES/会社前提.md`

## 使い方
1. 各社の `会社前提.md` を埋める（空欄は分かる範囲でOK、後から追記）。
2. AIに作業を頼むとき「○○社の前提を踏まえて」と伝えれば、ここを読んで動く。
3. 前提が変わったら、このファイルを更新するだけ。AIの認識も一緒に更新される。

> メモ（中身）ではなく「前提・設定」を置く場所。番号00＝すべての土台。
