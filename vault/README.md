# Obsidian Vault

[@minami_freeup さんのObsidianフォルダ構成記事](https://x.com/minami_freeup/status/2061559064237416599)を参考に作成したVault構造。

## コンセプト

> 集める → 出す の流れを作る。フォルダを役割で分けて、情報が流れる順に番号で並べる。
> これで、メモが「溜めるだけの場所」から「発信が出てくる場所」に変わる。

Vaultは大きく2つに分かれる。

1. **メイン部分（番号付き）** … 毎日触る／AIに整理してもらうところ
2. **`_system/`（裏方）** … AIに動いてもらうための裏方。普段は開かない

## 情報の流れ（番号＝作業の流れ・下から上へ）

```
完成        02_Contents        ← 出来上がったX投稿・記事・台本
  ↑
種にする    03_ContentSeeds    ← 発信の種（気づき・切り口）
  ↑
記録する    04_Daily / 05_Weekly / 06_Monthly   ← 日報・週報・月報
  ↑
整理する    07_Research        ← 外部記事をAIで要約・整理
  ↑
集める      01_Inbox（自分の言葉） / 08_Clipping（他人の言葉）
```

## フォルダ一覧

| フォルダ | 役割 |
| --- | --- |
| `01_Inbox` | 自分の未分類メモの入口（一次情報） |
| `02_Contents` | 完成したコンテンツの置き場（X投稿・記事・台本） |
| `03_ContentSeeds` | 発信の種 |
| `04_Daily` | 日報・デイリーノート |
| `05_Weekly` | 週報 |
| `06_Monthly` | 月報 |
| `07_Research` | 外部記事をAIで要約・整理した置き場 |
| `08_Clipping` | 外部記事のクリップ専用 |
| `99_System` | Vaultの使い方・ルール（取扱説明書） |
| `_system/` | AI作業用の裏方（AGENTS.md / CLAUDE.md / tools / AI作業用） |

詳しい運用ルールは [`99_System/Vault運用ガイド.md`](99_System/Vault運用ガイド.md) を参照。

---

※ フォルダは作り込みすぎないのがコツ。AIがいい感じに整理してくれる。
※ 04〜06は1つにまとめてもよいが、読みやすさのために分けている。
